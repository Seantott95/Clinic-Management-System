🩺 Clinic Management System

A full-stack clinical portal built from scratch using Object-Oriented PHP. This system handles end-to-end clinic operations, including patient record storage, automated appointment scheduling, and billing modules.

Tech Stack
Frontend: HTML5, Tailwind CSS
Backend: PHP (OOP)
Database: MySQL

✨ Key Features
Patient Management: Complete CRUD functionality for managing sensitive patient health profiles.
Scheduling Module: Automated appointment tracking and calendar coordination.
Billing & Invoicing: Generates transactional records for clinic visits.
Robust Security: Built with data sanitization, prepared SQL statements (PDO/MySQLi), and password hashing to prevent SQL injection and unauthorized access.
